# Lantern Ledger language

**Cage:** A connected group of cells with one shared rule. Its color is an aid; borders and a letter identify it too.

**Entry:** A committed number in a cell. It may be erased or replaced.

**Note:** A player-marked possibility, never a logical constraint.

**Possibility:** A value supported by row, column and cage rules under current entries.

**Contradiction:** Current entries admit no complete valid board.

**Hint:** An explained deduction from current entries and puzzle rules.

**Straight:** Distinct cage numbers forming an uninterrupted consecutive set, in any order.

**Completion badge:** A permanent record that a puzzle was completed; replay can have an unfinished board.
